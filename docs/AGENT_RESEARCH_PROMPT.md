# Agent 通用研究提示词

入口为 `jiuwen_agent/system_prompt.md`，由现有 agent_config 与主机 `--system-prompt` 加载。
本次仅调整研究流程与证据要求，工具、HSMM、优化器与保护条件沿用现有实现。

## 设计

1. 核对 anchor、历史、记忆、当前配置和能力。
2. 横向检查质量、通道区分力、时序、量值、模型门控和跨行为稳定性，再按信息价值深入。
3. 维持少量竞争假设，查询最能区分它们的正负对照与反例。
4. 自主选择四类干预，工具估计数值并验收。
5. 比较 incumbent、逐 episode 首次可见推送和实际校准结果。
6. 解决 trial，写最终审计，再更新有引用的条件性记忆。

保留每任务三次正式提案、两批负向诊断预算。横向检查是研究视角，不要求对每个维度机械调用工具。
没有内置传感器推荐权重、个人楼层、预设事件答案或目标阈值。
返回解释工具目前仅支持垂直折返校验，此限制单独描述为工具边界。

## 修复的提示词问题

- 消除“审计后停止”与“审计后更新记忆”的冲突。
- 将高度/返回优先调查改为按证据选择方向，保留真实工具限制。
- 不要求提前证明原因唯一成立才允许参数族试验。
- 明确 support_only 仍可接受正向进度证据，disambiguate 是附加上下文而非硬门。
- 区分零强度、事后匹配、历史标签、当前预测和重解释评分。
- 多轮提交/失败在现有审计字段中完整记述，不虚构逐动作审计或跨提案候选存储。
