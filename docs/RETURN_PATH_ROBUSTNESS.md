# Agent 返回路径与回放鲁棒性更新

本文件描述已落地的首版更新；不将后续软证据、传感器质量估计和全场景泛化视为已实现。

## 实现边界

实时调用链保持 `SceneEngine → 模板交互证据 → HSMM → 产品推送门控`。
Agent 低频读取历史、比较候选、提交结构；C++ 搜索前缀长度与强度，并执行逐样本保护。
Agent 不生成执行代码，也不直接写 HSMM 数值参数。

权威实现位于 `sa_cpp/src/context_template.cpp`，OHOS 副本通过同步脚本生成。
工具接口同时更新主机注册、SA 注册与 `jiuwen_agent/tools_contract.json`。

## 证据接口

`get_aborted_leave_candidates` 提供有序下降、回升、闭合时间，以及记录结束时间、
气压可用 tick 数、attached 字段覆盖和闭合后 attached 的首次出现时间。
同时报告候选总数、返回数和是否截断。

`attached_observed` 仅表示全程曾出现 attached。闭合后出现 attached 也仅能证明
该时刻观测为 attached，不能证明此前实际 detach 后发生了重新连接。
历史字段是融合布尔值，无法恢复 Wi-Fi 扫描质量；接口明确标记 unknown。
缺少 attached 不作为 C++ 返回提案的必要条件。

Prompt 要求对每个候选留下提出解释、证据不足或存在反证的处置，引用具体字段。
Agent 仍可能误读语义；自然语言解释不等于已验证事实，也不直接作为数值置信度。
目前候选处置覆盖要求由 prompt 与审计实现，尚非独立的强制 ledger 工具。

## schema 6：可替代的有序返回路径

新增可选字符串 `cancel_paths`。逗号表示先后，`|` 表示路径之间任选其一。
最多三条路径，每条最多六个事件，与旧 `cancel_sequence` 互斥。

```text
baro_ascending,vertical_closure|geo_outbound,approaching,attached
```

编译器接受两种已有原语能够表达的关系骨架：

- 回升发生在高度闭合之前。
- GPS 外向发生在接近之前，并以 attached 结束。

每条路径都只能在当前正向前缀开始之后匹配；每个 tick 最多推进一阶段。
气压返回事件要求 `baro_available`。路径从首个事件起180秒过期，outside 清理本次过程。
未完成的路径不额外施加负向分数，以减少短暂反转对提前推送的影响。
任何完整路径产生一次取消证据；路径之间不累加。
具有相同前缀的冗长路径被自动删除，例如已有 `回升,闭合` 时无需再保留 `回升,闭合,attached`。

新路径模式允许 approaching/attached 时保留返回匹配进度，但关闭正向输出。
因此接近不会在路径完成前清空所需历史。实时与离线使用同一匹配器。

取消保持最长120秒；连续10秒的新出发证据可提前解除。新出发需要未接近、未 attached，
同时出现有效气压下降且尚未闭合，或者步行与GPS外向共同成立。
180/120/10秒是本版固定工程边界，不是 Agent 学出的个人参数。

旧 schema 5 线性模板继续可读；正确标记观测有效性的真实历史上旧行为已做兼容回放。
本版没有为不存在的无线恢复原语伪造实现；一楼场景的独立标签验证仍待扩展。

## 校验和 Agent 的选择空间

返回解释校验要求下降后回升、回升后闭合，严格使用时间先后；不证明主观意图。
每条新路径必须单独匹配至少两个已校验返回 episode，不能借另一条路径的样本通过。
候选搜索仍同时比较未个性化基线和当前模板。

除已有误推、漏报和正常推送时间约束外，增加：

- 不得降低已识别返回的数量。
- 逐返回样本不得新增推送。
- 已有取消不得消失或变晚。

`diagnose_context_template` 新增 `ablation=cancel_path, path_index=N`，可移除某条路径查看贡献。
移除最后一条路径时仍保持新匹配器的其他行为，减少消融混入不同重置策略的干扰。
该消融是模型内部干预，不能证明真实世界物理因果。

## 实验数据错误与修正

旧多日准备脚本按每个 episode 重复读取同一源文件，使20条代表记录被写成6508个 tick。
修复后为794个唯一 tick。这个错误会使同一时刻被重复推断，旧重复历史的概率与评分不能沿用。
准备脚本现按唯一来源读取，并拒绝重复的 episode/时间键；不再把 outcome 时间伪装成推送时间。
C++ HSMM历史加载也拒绝同一 episode 内重复时间戳。
冻结模板评估遇到无效历史返回失败，不再包装为成功或降级为仅推送分数回放。

`compare_return_paths.py` 使用原始结果标签计算 TP/FN/FP/TN。
Agent 的 ABORTED_LEAVE 解释在两臂保持一致，但不能把原始 FALSE_PUSH 从准确率分母里移除。
旧优化评分仍保留历史的 lower-platform soft-positive 设计，所以其 false_kept=0 不等于实际零误推。

## 本次实际结果

Agent 成功运行并给出13个负样本候选的处置，提出5个返回解释，C++ 全部接纳。
之前未提交的无 attached 返回记录在本次被纳入。Agent 未申请垂直阈值调整。
Agent 提出了两条存在前缀包含关系的路径；最终编译器保留单条回升→闭合路径。
Agent 对部分 attached 仍使用了“重连”的措辞，此解释未被当作物理真值。

最终确定性重新校验保留：

```text
positive_sequence = baro_descending,lower_platform,geo_outbound
cancel_paths = baro_ascending,vertical_closure
negative_pattern = 空
ready_prefix_length = 2
strength = HIGH / 0.6
```

对比提交前旧二进制和最终新二进制，同一20条去重记录、相同 theta：

| 原始结果指标 | 旧版 | 新版 |
|---|---:|---:|
| 确认离开正确推送 | 7/7 | 7/7 |
| 原始负样本误推 | 7/13 | 7/13 |
| 原始结果正确率 | 65% | 65% |
| 返回路径识别 | 5 | 5 |
| 7条真实离开的推送时间变化 | 基准 | 平均提前7.14秒，最大20秒，无延后 |

旧匹配器本已能匹配这些垂直返回，Agent 先前遗漏解释不等于线上漏识别。
本次已验证收益是候选覆盖、输入可靠性、模板约束与推送提前量；没有证据宣称误推率下降。
五次返回的推送发生在可确认返回之前，后验取消不能撤销这些通知。
同一批数据也用于生成模板，本结果是回归结果，不是独立泛化测试或 Agent 不可替代性的证明。

## 复现工具

在 WSL/Linux 中使用以下脚本，均通过 `--help` 查看路径参数：

- `prepare_cancel_sequence_multiday.py`：准备去重多日证据。
- `run_return_path_agent.py`：在隔离目录调用真实 Jiuwen Agent；凭据以文件路径传入，不打印密钥。
- `validate_return_path_proposal.py`：仅提取 Agent 结构，用当前 C++ 重新搜索和校验数值。
- `compare_return_paths.py`：固定原始标签和同一解释文件，对比二进制和模板，保存每条推送时间。
- `test_cancel_dataset.py`：来源去重、重复时间戳和不伪造推送时间的回归测试。

个人模板、收发日志和逐样本时间只保留本地 output，不上传原始数据或凭据。

## 后续边界

连续软返回分数、原始 Wi-Fi 扫描质量、真实 detach-to-reattach 事件、非垂直返回标签验证，
以及按时间划分的独立数据验证尚未实现。后续收益应先由这些可观测能力和独立实验支撑，
不能单凭扩大原语目录或重新解释负样本宣称准确率提高。
