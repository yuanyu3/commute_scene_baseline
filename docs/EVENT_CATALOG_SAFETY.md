# 统一事实目录与组合安全

原语不带正负标签，不设置 allowed_roles。event_catalog.h 提供统一事实目录与三值判定，
Context Template 的正向、负向、返回和前缀结构决定组合的用途。
不再根据 no_ 名称禁止事实用于序列。

## 已实现的组合校验

- 生成、加载、负向批量评估均校验同 tick 的矛盾条件：
  geo_outbound 与 no_geo_outbound、下降/低平台与 no_baro_descent 不能同时成立。
- 跨 tick 的 A 然后 not-A 是合法变化，不按上述同刻矛盾拒绝。
- 返回单序列和多路径均检查物理逆转顺序；历史匹配和回放保护继续生效。
- 原有预算、路径时效、上下文重置、独立强度校准、重复证据取最大值与提交保护保留。
- UNKNOWN 不推进序列，不等于 FALSE。
- disambiguate 等待的下一事件为 UNKNOWN 时，不输出该未完成前缀的负向证据。

## GPS 慢刷新

SA 将定位 observed_at 传入 BaselineRuntime 和 SceneEngine，区别于处理 tick 的时间。
位置相同但采样时间不同属于新观测；重复同一采样时间属于缓存，不能据此声称没有外向。
速度可靠度按两个定位采样时间的间隔计算，避免把20秒位移除以1秒 tick 间隔。

当前保守有效性界限：

| 条件 | 处理 |
|---|---|
| 首次定位 | 无方向观测对，UNKNOWN |
| 5秒或20秒等慢刷新 | 有新可靠定位对可参与判断 |
| 重复使用同一定位 | GPS原语UNKNOWN；不重复证明无外向 |
| 最新定位年龄超过30秒 | GPS定位过期，不能作为当前空间关系/方向 |
| 两次定位间隔超过120秒 | 本次方向UNKNOWN，等待后续有效观测对 |
| 可靠度低于0.5、缺精度、非有限值 | 不形成可靠无外向事实 |
| 倒序/未来定位时间 | 不形成有效方向观测，也不污染后续时间基准 |

30秒和120秒是当前固定工程边界，不是从个人数据学出的最优值。目录公开这些边界，
Agent不能直接修改。当前 no_geo_outbound 仅表示在有效观测下外向分数低，不证明人静止。
条件缺失等待机制已删除，仅保留基于序列进度的 disambiguate。

policy_history 同时保存 geo_observation_known、geo_fix_age_s、geo_fix_interval_s、
geo_reliability。回放和Agent时序查询读取这些字段。旧历史缺字段时按UNKNOWN处理，
不得把缺少定位时间误当成新鲜定位。旧数值观测仍可供原有基线回放，不能据此验证新的
实时GPS采样时间处理；该部分通过合成定位时间测试覆盖。

## 范围与限制

气压、GPS和空间关系支持显式UNKNOWN。Motion/PDR/Radio旧语义接口仍不具备完整通道有效性
标记，目录明确披露这一限制；没有增加基于这些通道缺测的取反或缺失计时机制。
本次没有加入任意代码生成、通用逻辑语言或新的LLM调用。

冻结的47条历史回放：普通误推0、漏报0、确认离开27、平均提前量51.4815秒；
逐episode推送与原冻结实现一致。另有6条ABORTED_LEAVE过程仍有可见推送，
不能将上述普通误推0表述为全部负标签均未推送。
